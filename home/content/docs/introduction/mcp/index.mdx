---
title: MCP (Model Context Protocol)
description: Connect an MCP client to a Storyden community and discover its available tools.
---

Storyden can expose community content and actions through an MCP server. The server is optional: an operator enables it with `MCP_ENABLED=true`. The endpoint is the **public API origin** followed by `/mcp`, which may be on a different domain from the community's web site. Use the endpoint advertised by the community rather than assuming both origins are the same.

## Discover a community's MCP endpoint

Start at the community's web origin and read `/.well-known/ai-catalog.json`. When MCP is enabled, its `entries` include a URL for the [MCP Server Card](https://github.com/modelcontextprotocol/modelcontextprotocol/blob/main/seps/2127-mcp-server-cards.md). The card describes the server and its Streamable HTTP endpoint. The community's `/developers` page and `/llms.txt` link to the same discovery documents. An empty `entries` list means this instance does not advertise MCP.

For example, a deployment with `https://community.example` as its web origin and `https://api.community.example` as its API origin publishes the catalog at `https://community.example/.well-known/ai-catalog.json`; the card may point to `https://api.community.example/mcp`.

The Server Card intentionally does **not** list tools. Connect and use MCP's normal `tools/list` operation to discover the tools available to your identity. The list can change with server version and permissions.

## Authenticate

The MCP endpoint requires an authenticated identity. A member can create an [access key](/docs/reference/access-keys) and supply it to an MCP client as a bearer token. The key carries the member's current permissions. Where Storyden's OAuth server is enabled, clients can instead use its [OAuth flows](/docs/introduction/oauth) and follow the instance's authorization discovery metadata. OAuth client registration and autonomous bot registration are controlled separately by the operator; neither is implied by MCP being enabled. See [client registration](/docs/introduction/oauth/client-registration) for the available policies.

Treat the credential as a secret. Give an agent the minimum permissions its task needs and review tool calls that write or moderate community content.

## Example workflow

An agent helping maintain a community bookmark directory can search existing pages and tags, inspect a page tree, then create or update a page if its identity is allowed to do so. Tool names and schemas should come from that instance's MCP `tools/list` response, not from a hard-coded list in an integration.

For scripts that call the REST API directly, see the [API guide](/docs/api) and [Storyden CLI](/docs/introduction/cli).
